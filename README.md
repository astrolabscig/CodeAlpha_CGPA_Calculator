# CGPA Calculator

A console-based CGPA Calculator built in C++ as part of my CodeAlpha internship.

## Features
- Calculates weighted CGPA based on grade points and credit hours
- Validates all user input (rejects letters, negatives, and out-of-range values)
- Displays total credit hours and final CGPA
- Clean, user-friendly terminal interface

## How To Run
1. Compile: g++ cgpa_calculator.cpp -o cgpa_calculator
2. Run: ./cgpa_calculator (Mac/Linux) or cgpa_calculator (Windows)

## Grade Scale Used
| Grade | Points |
|-------|--------|
| A     | 4.0    |
| B+    | 3.5    |
| B     | 3.0    |
| C+    | 2.5    |
| C     | 2.0    |
| D     | 1.0    |
| F     | 0.0    |
